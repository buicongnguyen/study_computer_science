# Curriculum Plan

This file explains the source-backed course tree used inside the app. The module groupings are app-friendly summaries derived from the official course pages listed under each course.

## Algorithms

Sources:

- MIT OpenCourseWare 6.006 lecture notes: <https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/pages/lecture-notes/>

Tree:

- Foundations & Analysis
  - Algorithmic thinking
  - Asymptotic analysis
  - Correctness arguments
- Sorting & Search Structures
  - Comparison sorting
  - Heaps and ordered trees
  - Linear sorting
- Graph Search & Shortest Paths
  - Breadth-first search
  - Depth-first search and topological sorting
  - Shortest-path algorithms
- Dynamic Programming & Limits
  - DP patterns
  - Classic applications
  - Complexity perspective
